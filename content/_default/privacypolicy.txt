1.3 本政策说明本软件处理的信息类型、处理目的、存储

1.4 本政策仅适用于本软件。用户在 FimTale 站点上的

二、数据处理一览表
============================================================

本软件处理的信息汇总如下：

  APIKey / APIPass
    存储：本地 DPAPI 加密文件
    用途：作为身份凭证调用 FimTale API
    上传：仅发送至 FimTale 服务器

  TOTP 密钥
    存储：本地 DPAPI 加密文件
    用途：本地双因素验证
    上传：否，完全本地

  U 盘标识哈希
    存储：本地 DPAPI 加密文件
    用途：本地 U 盘解锁验证
    上传：否，完全本地

  阅读进度 / 缓存内容
    存储：本地 %APPDATA%/FimtaleClient/reader_cache/
    用途：提升加载速度、记录进度、缓存帖子图片
    上传：否，完全本地

  主题 / 界面设置
    存储：本地 config/UserSettings.json
    用途：记住用户偏好
    上传：否，完全本地

  隐私政策已读状态
    存储：本地 config/UserSettings.json
    用途：避免重复弹窗
    上传：否，完全本地

  操作系统环境（系统指纹）
    存储：不落盘，仅在内存中即时使用
    用途：判断是否为真实使用环境
    上传：否，完全本地

说明：
  - DPAPI 指 Windows 数据保护 API
    （Data Protection API），由操作系统提供，用于
    对本机保存的敏感数据进行加密。其加密密钥与当前
    Windows 用户账户绑定。
  - 除 APIKey / APIPass 在调用 FimTale API 时按
    协议发送至 FimTale 服务器外，其余数据均不离开
    用户本机设备。
  - 上述本地数据的存储期限由用户自行控制。用户未主
    动删除的，数据将持续保存在本机，直至用户卸载本
    软件或手动清除。

三、各项数据处理细则
============================================================

3.1 APIKey / APIPass

    用途：作为用户身份凭证，用于通过 FimTale 公开
    API 完成登录、绑定，并获取用户账号下的文章信息、
    用户设置信息及其他为提供服务所必需的内容。

    存储位置：本地 DPAPI 加密文件。

    是否上传：调用 FimTale API 时，作为身份凭证发送
    至 FimTale 服务器。此为完成登录与内容获取所必需。
    本软件不将其发送至 FimTale 以外的任何服务器。

    存储条件：仅在用户主动勾选“记住密码”时持久化
    保存；未勾选时不写入磁盘。

3.2 TOTP 密钥

    用途：为本软件提供本地式 TOTP 二次验证能力。

    说明：该 TOTP 仅绑定于 FluentTale Client 本地，
    不绑定至用户 FimTale 账号，不回传至 FimTale。
    其与 APIKey 一一对应，用于在本机校验操作者身份。

    存储位置：本地 DPAPI 加密文件。

    是否上传：否，完全本地。

    是否必选：完全可选，仅在用户自愿同意时添加。

    例外情形：本软件判定为“高危环境”时，为保护
    用户账号与操作安全，可能要求强制绑定。该机制在
    正常使用条件下不触发；触发时本软件将予以明确
    提示。

    触发条件：客户端本地风控评分达到“高危”阈值（如
    虚拟机环境、异常时区、系统信息异常等）。用户
    拒绝绑定的，可选择不继续登录，本软件不会在用户
    拒绝后强行绑定。

3.3 U 盘标识哈希

    用途：用于本地 U 盘解锁验证，作为本软件的一种
    本地安全校验手段。

    存储位置：本地 DPAPI 加密文件。

    是否上传：否，完全本地。

3.4 阅读进度 / 缓存内容

    用途：提升加载速度、记录阅读进度、缓存帖子图片。

    存储位置：
    %APPDATA%/FimtaleClient/reader_cache/

    是否上传：否，完全本地。

    说明：
    - 帖子缓存（原始 API 响应）最多保留 200 条，
      按访问时间 LRU 淘汰；
    - 图片缓存受容量上限约束，超出时按最久未访问
      优先删除；
    - 用户可在设置页面手动清理缓存；
    - 卸载本软件后，缓存目录残留不会自动删除，
      用户可手动清理。

3.5 主题 / 界面设置

    用途：记录用户界面偏好，例如主题、布局等。

    存储位置：本地 config/UserSettings.json。

    是否上传：否，完全本地。

3.6 隐私政策已读状态

    用途：记录用户已阅读的政策版本号，当政策发生
    变更时重新提示用户阅读与确认。

    存储位置：本地 config/UserSettings.json。

    是否上传：否，完全本地。

3.7 操作系统环境检测（System API）

    用途：检测是否具有“人类使用特征”，用于防止
    恶意使用、批量滥用、自动化攻击等行为。

    具体行为：
    - 读取操作系统自身提供的基本环境信息，包括：
      屏幕分辨率与显示器数量、系统运行时长、系统
      安装天数、物理内存容量、CPU 核心数、系统盘
      剩余空间、计算机名、时区、系统语言。

    声明：
    - 上述信息均为操作系统元数据，不涉及任何用户
      安装的第三方软件、文件内容、聊天记录、账号
      信息；
    - 本软件不读取、不记录任何用户安装的第三方
      软件信息；
    - 检测结果仅在内存中即时使用，不写入磁盘，不
      上传至任何服务器；
    - 该检测完全在本地进行，不产生任何持久化记录，
      不关联到任何具体用户身份；
    - 该检测是客户端风控机制的组成部分，用于防止
      批量自动化滥用等行为，保护 FimTale 站点与
      正常用户的权益。

六、信息安全
============================================================

6.1 本软件对本地保存的敏感数据（APIKey / APIPass、
    TOTP 密钥、U 盘标识哈希）采用 Windows DPAPI
    加密。该加密机制由操作系统提供，加密密钥与当前
    Windows 用户账户绑定，其他用户账户无法直接解密。

6.2 本软件为纯客户端工具，信息默认仅存储于本机。
    安全边界主要取决于用户设备环境。用户应妥善保管
    本机访问权限，避免他人在未经授权的情况下使用
    其设备。

6.3 用户应为操作系统设置登录密码，并定期检查本软件
    配置目录下的凭据文件。

6.4 用户怀疑凭据已泄露的，应及时在 FimTale 侧更换
    密码，并在本软件中清除已保存的 APIKey / APIPass
    与 TOTP 信息。
